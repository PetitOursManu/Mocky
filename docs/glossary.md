# Glossary

## Muse {#muse}

The design-intelligence switch. It turns a prompt into a distinctive art direction, with real copy, a coherent palette and real generated images, grounded in award-winning references looked up live through local MCP servers.

## Design direction {#direction}

The one style a project keeps, so its screens look like one product rather than five sketches. The first screen sets it; **New direction** rewrites it for the screens that follow.

## DESIGN.md {#design-md}

A portable design system in plain Markdown: colour tokens, typography, spacing, component patterns. Mocky puts it at the head of every generation, and a project falls back on it until it has a direction of its own.

## Composer {#composer}

The floating bar at the bottom of the canvas, where a screen is described. It is the only control in the product that changes verb depending on what is selected.

## Motion Ultra {#motion-ultra}

A project setting that storyboards each new screen, generates a series of ×3 or ×6 pictures in one style for it, and writes it as a page carried by motion. The same name covers the `.mp4` films composed for a screen.

## Quality pass {#quality-pass}

On request, Mocky checks a screen against 59 deterministic rules and a judged pass, scores it out of 20, and can fix what it found. It never runs by itself.

## Capability {#capability}

Code Mocky injects into the preview so that a generated component can use what it did not write itself: icons, charts, animations, 3D scenes.

## Invariant {#invariant}

A rule the code refuses to break, each one written after a specific bug. Five series: I (core), M (Muse), Q (quality), U (Motion Ultra), D (admin dashboard).

## Screen type {#screen-type}

What kind of screen the next generation is — a dashboard, a planning, a pricing page — or what kind of document. Chosen in the composer, it gives the model the structure that kind of screen expects; your words still win. It stays armed for the project's next screens.

## Document {#document}

A screen made of pages of a fixed size — a flyer, a report, a résumé, a social media post — rather than a page laid out for a viewport. It downloads as a PDF with fillable fields, a `.pptx` with editable text, or PNG images. See [Documents and social posts](documents.md).

## Page format {#page-format}

The size of a document's pages: A4, A3 or US Letter in portrait or landscape, a 16:9 slide, or a social media size (1:1, 4:5, 9:16, 1.91:1). It replaces the Mobile / Desktop / Tablet presets for a document.

## Cable {#cable}

A link between two screens as the canvas draws it: a line from the element it was placed on to the screen it opens, like a mind map. Faint behind the frames outside link mode; a control you can remove or reconnect inside it.
